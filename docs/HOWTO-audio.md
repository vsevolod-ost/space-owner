# How to add music and sounds

Everything the sound designer touches: the files, the registry, which location plays which
track, where sound effects come from, and the volume settings. The code behind it is
`src/core/audio/AudioService.ts`, reached everywhere as `services.audio`.

## Files and formats

Sound files live in `public/assets/audio/`. Give every real sound two formats of the same
recording, **`ogg` and `mp3`**: the game lists both and the browser plays the first one it
supports (Phaser's `load.audio(key, [urls])`). Keep music loops short enough to download fast
(a few MB at most) and cut them so the end runs into the start without a click.

The files there now are **placeholders** (`ui-click.wav`, `sfx-door.wav`, `music-demo.wav`),
generated by `python3 tools/sounds.py` (needs `numpy`). WAV is fine for placeholders, too big for
real music.

| Key          | Placeholder file       | What it is                                  |
| ------------ | ---------------------- | ------------------------------------------- |
| `ui-click`   | `audio/ui-click.wav`   | Any button click or menu choice (60 ms bip) |
| `sfx-door`   | `audio/sfx-door.wav`   | The hero walks through a door               |
| `sfx-alarm`  | `audio/sfx-alarm.wav`  | Navigation panel alarm: a death is near     |
| `music-demo` | `audio/music-demo.wav` | Quiet 4 s loop of the demo locations        |

## Add a sound to the registry

Every sound has a key in `src/assets/audio.ts`; the object key is the key code uses
(`AudioKey`), so a typo in a key is a compile error.

```ts
export const audio = {
  // ...
  'music-bridge': { paths: ['assets/audio/music-bridge.ogg', 'assets/audio/music-bridge.mp3'] },
  'sfx-alarm': { paths: ['assets/audio/sfx-alarm.ogg', 'assets/audio/sfx-alarm.mp3'] },
} as const satisfies Record<string, AudioEntry>;
```

Paths are relative to `public/`. `BootScene` loads everything in the registry before the menu
shows, so a sound needs nothing else. A path to a missing file fails the smoke check (HTTP 404):
add the files and the entry in the same commit. Naming: `music-*` for music, `sfx-*` for
effects, `ui-*` for interface sounds, kebab-case.

### Replace a placeholder

Either put the real `ogg` + `mp3` next to the placeholder and change `paths` of that key (then
delete the wav), or overwrite the wav with a wav of the same name. The key stays, so no other
code changes. Do not run `python3 tools/sounds.py` after that: it rewrites **every** placeholder
file and would overwrite real sounds kept under a placeholder name - if you do, check
`git status` and restore them (`git checkout -- <file>`).

## Music of a location

A location plays its track when the hero enters it: the `music` field of its definition in
`src/content/locations/<id>.ts`.

```ts
export const warehouse: LocationDef = {
  title: 'Warehouse',
  // ...
  music: 'music-demo',
};
```

- Two locations with the **same** track: walking between them does not restart it, the music
  just continues (home and the warehouse both use `music-demo`).
- A **different** track crossfades over 0.5 s.
- A location **without** `music` keeps whatever plays now. To silence a location, give it a
  quiet track or call `services.audio.stopMusic()` from its script. The ship deck (act 2) has
  no `music` yet, so `music-demo` from the warehouse continues there; give it its own track.
- The main menu and the end screens have no music: going there fades the track out (0.25 s).
  Menu music is not done yet; see "Not done yet" below.

From code (a cutscene, a trigger, a story act) music is switched with:

```ts
import { services } from '@/core/services';

services.audio.playMusic('music-bridge'); // crossfade 500 ms, loops
services.audio.playMusic('music-alarm', { fadeMs: 100 }); // fast switch
services.audio.playMusic('music-ending', { loop: false });
services.audio.stopMusic(1000); // fade out over 1 s
```

The next location the hero enters with its own `music` switches it again.

## Sound effects

```ts
services.audio.playSfx('sfx-alarm');
services.audio.playSfx('sfx-alarm', { volume: 0.5 }); // half as loud as the SFX setting
```

Where the game already plays sounds:

| Sound      | Played by                                                                    |
| ---------- | ---------------------------------------------------------------------------- |
| `ui-click` | every `Button` click and every `ChoiceList` choice (menus, pause, dialogues) |
| `sfx-door` | walking into a door (`src/world/Interactables.ts`), not a scripted `goTo`    |

In a **cutscene** script (docs/HOWTO-cutscene.md) use the API: `api.playSfx('sfx-alarm')`. In a
location's interactable or trigger (`run: (ctx) => ...`) and anywhere else, import `services` as
above. A UI sound for a new kind of control goes into that control in `src/ui/kit/`.

## Volumes and the settings panel

The player has two volumes, **Music** and **SFX**, each 0..1 (shown as 0..100%). They are
stored in the browser's `localStorage` under `space-owner.settings`, apart from the saved game, so
New Game never resets them. Defaults: music 70%, SFX 80% (`src/core/settings/SettingsService.ts`).

The settings panel (`src/scenes/SettingsScene.ts`) opens from the main menu's **Settings** button
and from the pause menu's **Settings** item. "-" / "+" change a volume by 10%; keyboard: Up/Down
picks a row, Left/Right changes it, Enter on Back or Esc closes.

In code, read volumes with `services.audio.musicVolume` / `sfxVolume` and change them only with
`services.audio.setMusicVolume(v)` / `setSfxVolume(v)`: these store the value and apply it to the
music at once. (Writing `services.settings` directly stores it but leaves the playing track at
the old loudness.)

How loud a sound plays: an effect at `volume` plays at `volume x SFX setting`; music plays at
`fade x Music setting`. Mix the files themselves so that at 100% nothing clips and the music
sits under the effects.

## The first click rule

Browsers keep a page silent until the player clicks or presses a key on it (autoplay policy).
The game handles it:

- music asked for before that first input waits and starts on it;
- sound effects asked for before it are skipped (there is nothing to hear anyway);
- nothing throws or logs an error.

So when testing, click the game once (or press a key) before listening. The smoke tool does the
same with `h.click()` before it checks audio (`tools/smoke/scenarios/audio.mjs`).

To see what plays, open the browser console with `?debug=1` in the URL:

```js
nasa.services.audio.debugInfo(); // { music: 'music-demo', locked: false, tracks: [...] }
nasa.game.sound.getAllPlaying().map((s) => s.key);
```

## Not done yet (extension points)

- **Menu music.** Add a `music-menu` key and call `services.audio.playMusic('music-menu')` in
  `MainMenuScene.create`; the world's tracks crossfade from it on New Game / Continue.
- **Ambient layer.** One music track plays at a time. A second loop under it (engine hum,
  wind) would be a second set of tracks in `AudioService` with its own `playAmbient(key)` and
  an `ambient` field on `LocationDef`.
- **Footsteps.** `Player` (src/world/Player.ts) knows when the hero walks; a step sound would be
  played there on animation frames, with a surface per location or per map region.
- **Spatial sound** (louder near the source), music by story event, a mute key: not planned yet.
